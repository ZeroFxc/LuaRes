Lua 模块在 WASM 内置 Lua 环境中运行，可访问全部 luac.* 函数。模块是一个 Lua chunk，执行后必须返回一个 table。

      
return {
    name        = "my_obfuscator",  -- 必填，唯一标识符
    label       = "我的混淆器",       -- 可选，显示名称
    description = "模块功能描述",     -- 可选

    -- 必填，混淆入口函数
    -- proto: luac.Proto userdata
    apply = function(proto)
        -- 可读写 proto 字段：
        --   proto.code       table  指令数组 (1-based, 32-bit integer)
        --   proto.k          table  常量表 (1-based)
        --   proto.p          table  子 Proto 数组 (1-based)
        --   proto.sizecode   number 指令数量 (可写)
        --   proto.sizek      number 常量数量
        --   proto.sizep      number 子 proto 数量
        --   proto.numparams  number 参数数量 (可写)
        --   proto.is_vararg  number 是否可变参数 (可写)
        --   proto.linedefined number 起始行号 (可写)

        -- 指令操作函数：
        --   luac.GET_OPCODE(inst)  luac.SET_OPCODE(inst, op)
        --   luac.GETARG_A(inst)    luac.SETARG_A(inst, a)
        --   luac.GETARG_B(inst)    luac.SETARG_B(inst, b)
        --   luac.GETARG_C(inst)    luac.SETARG_C(inst, c)
        --   luac.GETARG_Bx(inst)   luac.SETARG_Bx(inst, bx)
        --   luac.GETARG_sBx(inst)  luac.SETARG_sBx(inst, sbx)
        --   luac.GETARG_Ax(inst)   luac.SETARG_Ax(inst, ax)
        --   luac.CREATE_ABC(op,a,b,c)
        --   luac.CREATE_ABx(op,a,bx)
        --   luac.CREATE_AsBx(op,a,sbx)
        --   luac.CREATE_Ax(op,ax)

        -- 操作码常量：luac.OP_MOVE, luac.OP_LOADK, ... luac.OP_EXTRAARG(47)
        -- 扩展操作码：luac.OP_FULLOPSIZE(48)
        -- 操作码名称表：luac.OPCODE_NAMES[1..47]

        -- 字节码导入导出：
        --   luac.undump(str, force_encrypted) -> proto
        --   luac.dump(proto) -> str

        -- 可直接调用内置混淆模块：
        --   luac.bool_obfuscate_c(proto)
        --   luac.num_obfuscate_c(proto)
        --   luac.str_encrypt_c(proto)
        --   ... 等全部 19 个内置模块

        -- 示例：在末尾插入 MOVE 0 0
        local n = proto.sizecode
        proto.code[n+1] = luac.CREATE_ABC(luac.OP_MOVE, 0, 0, 0)
        proto.sizecode = n + 1

        return true  -- 成功返回 true
    end
}

      
模块按注册顺序在内置模块之后执行。修改 proto.code 后必须同步更新 proto.sizecode。
